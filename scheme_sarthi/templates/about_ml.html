💡 How Random Forest Ensemble Works in Scheme Sarthi

1. One-Hot Vectorization

User inputs (Age, Income, Student, Disability, Rural/Urban, Category) are converted into a continuous 10-dimensional numerical feature vector.

2. Decision Trees Voting

Each scheme has a dedicated 100-tree Random Forest ensemble. Each tree evaluates subsets of features and votes on eligibility.

3. Gap Analysis Harmonization

Random Forest probability scores are harmonized with deterministic rule checks to classify into Eligible, Almost Eligible, and Not Eligible.
